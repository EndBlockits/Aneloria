# ANELORIA

**RPG-сервер Minecraft: шесть рас, расовые испытания, континент 8000 × 8000 и Лабиринт, который каждый раз другой.**

Aneloria is a custom Minecraft Java 1.20.1 MMORPG server with an original RPG layer inspired by the manhwa "Surviving the Game as a Barbarian" (Dungeon & Stone). Built solo by a 20-year-old developer from Kazakhstan. No client mods required.

> Статус: в разработке, сервер пока не открыт. Адрес появится на сайте, когда начнётся тестирование.

## Что это

Ты попадаешь в игру одной из шести рас и выживаешь дальше только вместе с другими. Первые часы идут в одном порядке:

1. **Пролог** — дорога домой, тёмная комната, монитор. Одно нажатие «Войти» — и стул перед экраном пуст.
2. **Выбор расы и класса** — на платформе над облаками.
3. **Расовое испытание** — у каждой расы свой наставник и своя механика.
4. **Расовый город** — первые задания и первые союзники.
5. **Континент** — открытый мир 8000 × 8000 блоков, кланы.
6. **Лабиринт** — главное испытание. Портал открывается волнами.

## Чем отличается

- **Свои модели и NPC** — наставники, хранители и существа на собственных моделях, а не на обычных мобах.
- **Свой интерфейс** — окно статуса с портретом расы, здоровьем, маной и строкой задания вместо таблицы сбоку.
- **Игра в команде** — способности раскрываются рядом с союзниками.
- **Испытания без гугла** — цель всегда понятна, подсказки показывают направление и расстояние.
- **Без модов** — всё приходит с ресурспаком, который загружается сам.

## Технически

- **Ядро:** Paper 1.20.1, клиент Java Edition 1.20.1.
- **Свои плагины:** BarbarianRPG (расы, классы, пролог, испытания, Лабиринт) и AneloriaFloors (второй этаж).
- **Используются:** MythicMobs, ModelEngine, BetterHud, AuthMe, ItemsAdder.
- **Языки интерфейса:** русский и английский.
- **Прогресс** привязан к UUID аккаунта.
