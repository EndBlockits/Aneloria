# 06 · Сайт

*14 ноября 2026 · версия 2*

## Что это

Одна страница без сборки и зависимостей: [`docs/index.html`](../docs/index.html). Разметка, стили и скрипт лежат в одном файле, снаружи подгружаются только шрифты.

## Разделы

- Главный экран с анимированным порталом Лабиринта.
- Путь игрока: от пролога до Лабиринта.
- Расы.
- Мир: цифры и схема континента.
- Лабиринт по этажам.
- Чем сервер отличается.
- Ход разработки.
- Как зайти.
- Вопросы и ответы.
- Политика конфиденциальности.

## Что изменилось во второй версии

- Путь игрока переписан под новый пролог.
- Добавлены разделы про расы, этажи Лабиринта, ход разработки и вопросы.
- Шапка прилипает к верху и подсвечивает текущий раздел.
- Портал перестаёт анимироваться, когда уходит за экран, и стоит на месте, если в системе отключены анимации.

## Как менять данные

В начале скрипта есть блок `SITE`:

```js
const SITE = {
  ip: "",       // адрес сервера
  contact: "",  // почта или ник для связи
  links: []     // соцсети: { name: "Discord", url: "https://..." }
};
```

Пока поля пустые, на странице стоят заглушки, а кнопка «Скопировать адрес» скрыта. Достаточно вписать значения — страница обновится сама.

## Публикация

Папка `docs/` подготовлена под GitHub Pages: Settings → Pages → ветка `main`, папка `/docs`.
